# 🐍 Python Bootcamp: Fundamentals and Algorithms (Project 01)

## 📌 О проекте
Фундаментальный проект по освоению языка Python, охватывающий работу со стандартными потоками ввода-вывода, файловыми операциями, базовыми и сложными структурами данных, а также реализацию классических алгоритмических паттернов. В рамках проекта решены задачи на математические вычисления, обработку JSON, динамическое программирование и оптимизацию поиска с обязательной валидацией входных данных.

## 📂 Структура проекта
Каждая задача оформлена как независимый модуль в собственной директории в соответствии с требованиями. Решения находятся в папке `src/`:
- 📁 **`src/exercise1/`** → 📄 `task1.py` (Скалярное произведение векторов)
- 📁 **`src/exercise2/`** → 📄 `task2.py` (Проверка числового палиндрома без использования строк)
- 📁 **`src/exercise3/`** → 📄 `task3.py` (Анализ матрицы и подсчет фигур из файла `input.txt`)
- 📁 **`src/exercise4/`** → 📄 `task4.py` (Генерация треугольника Паскаля с валидацией ввода)
- 📁 **`src/exercise5/`** → 📄 `task5.py` (Кастомный парсинг строки в float с обработкой ошибок)
- 📁 **`src/exercise6/`** → 📄 `task6.py` (Слияние двух отсортированных JSON-списков)
- 📁 **`src/exercise7/`** → 📄 `task7.py` (Поиск пути с максимальной суммой: динамическое программирование)
- 📁 **`src/exercise8/`** → 📄 `task8.py` (Подсчет уникальных элементов с использованием множеств)
- 📁 **`src/exercise9/`** → 📄 `task9.py` (Вычисление производной многочлена в заданной точке)
- 📁 **`src/exercise10/`** → 📄 `task10.py` (Оптимизационная задача выбора аппаратов с хешированием)

## 🛠 Стек технологий и инструменты
- **Язык:** Python 3.x
- **Стандартная библиотека:** `sys` (stdin/stdout), `json` (парсинг и сериализация), `typing` (аннотации типов)
- **Алгоритмические концепции:** Динамическое программирование (DP), два указателя (Two Pointers), хеш-таблицы (`dict`/`set`), математический парсинг.
- **Работа с данными:** Чтение/запись файлов, обработка исключений (`try`/`except`).

## ⚙️ Детальное описание выполненных задач

- **Part 1. Математика и базовые алгоритмы (Tasks 01, 02, 09):**  
  Реализовал вычисление скалярного произведения векторов через стандартный ввод. Для задачи с палиндромом применил **чисто математический подход** (через операции деления нацело и остатка от деления), строго соблюдая запрет на использование строковых преобразований. В задаче с производной написал парсер коэффициентов многочлена и реализовал формулу вычисления значения производной в заданной точке.

- **Part 2. Работа с матрицами и файлами (Tasks 03, 07):**  
  Написал скрипт для чтения квадратной матрицы из `input.txt` и классификации фигур (квадраты и круги) на основе анализа паттернов единиц. Для задачи о роботе реализовал классический алгоритм **динамического программирования**, который за $O(N \times M)$ находит путь с максимальной суммой монет, избегая неэффективного рекурсивного перебора всех вариантов.

- **Part 3. Валидация и кастомная логика (Tasks 04, 05):**  
  Создал генератор треугольника Паскаля с надежной обработкой некорректного ввода (например, буквенных символов), возвращающей понятное сообщение об ошибке. В задаче 05 реализовал **собственный алгоритм преобразования строки в вещественное число** (аналог встроенной `float()`), корректно обрабатывающий знаки, целую и дробную части, без использования функций кастинга.

- **Part 4. Структуры данных и оптимизация (Tasks 06, 08, 10):**  
  - *Task 06:* Реализовал эффективное слияние двух заранее отсортированных JSON-списков за линейное время $O(N+M)$ (алгоритм слияния как в Merge Sort), добавив проверку на пустой файл и невалидный JSON.
  - *Task 08:* Использовал структуру данных `set` (множество) для подсчета уникальных чисел, обеспечив среднюю сложность вставки и проверки $O(1)$.
  - *Task 10:* Решил задачу условной оптимизации (поиск двух аппаратов с одинаковым годом, заданной суммой времени и минимальной стоимостью), сгруппировав данные по году выпуска в словаре (`dict`) для быстрого поиска подходящих пар.
