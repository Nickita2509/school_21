# 🚀 School 21 DevOps Portfolio

Коллекция инженерных проектов, выполненных в рамках образовательной программы Школы 21.

Портфолио демонстрирует практические навыки системного администрирования Linux, настройки сетевой инфраструктуры, написания Bash-скриптов, мониторинга, контейнеризации и работы с реляционными базами данных.

---

## 🗂️ Инфраструктурные проекты

### 🐧 [DO1: Linux (Ubuntu Server)](./D01_Linux.ID_356272-2)

Развертывание и комплексное администрирование Ubuntu Server.

- **Ключевые навыки:** управление пользователями и правами (`sudo`, `adm`), настройка сети через `netplan`, статический IP, DNS.
- **Безопасность:** hardening SSH, настройка нестандартного SSH-порта.
- **Диагностика:** мониторинг ресурсов (`top`, `htop`, `df`, `du`), анализ системных логов (`/var/log/auth.log`, `syslog`).
- **Автоматизация:** планирование задач через `cron`.

### 🌐 [DO2: Linux Network](./DO2_LinuxNetwork.ID_356275-1)

Проектирование и настройка многосегментной компьютерной сети на базе виртуальных машин.

- **Ключевые навыки:** статическая маршрутизация, настройка firewall через `iptables`.
- **Firewall:** стратегии `default-deny` / `default-allow`.
- **Сетевые сервисы:** DHCP с резервированием по MAC, NAT (`SNAT`/`DNAT`).
- **SSH:** Local и Remote TCP Forwarding.
- **Диагностика:** `tcpdump`, `nmap`, `iperf3`, `traceroute`.

### 📊 [DO3: Linux Monitoring & Bash Scripting](./DO3_LinuxMonitoring_v1.0.ID_356278-1)

Разработка модульных Bash-скриптов для автоматизации сбора системных метрик и аудита.

- **Ключевые навыки:** структурированный Bash-код, валидация ввода, парсинг конфигурационных файлов.
- **Аудит файловой системы:** рекурсивный анализ директорий, MD5-хеширование, статистика по типам файлов.
- **Терминал:** работа с ANSI escape codes и форматированием вывода.
- **Оптимизация:** измерение времени выполнения скриптов.

### 📈 [DO4: Linux Monitoring v2.0](./DO4_LinuxMonitoring_v2.0.ID_356280-1)

Комплексное решение для генерации нагрузки, парсинга логов и мониторинга системы в реальном времени.

- **Логи:** генерация синтетических логов Nginx в формате `combined`.
- **Парсинг:** обработка логов через `awk`.
- **Визуализация:** GoAccess.
- **Мониторинг:** Prometheus, Grafana, Node Exporter.
- **Нагрузочное тестирование:** `stress`, `iperf3`.
- **Автоматизация:** собственный Bash-экспортер метрик для Prometheus.

## 🐳 Контейнеризация

### 🐳 [DO5: Simple Docker](./DO5_SimpleDocker_ID_356282-1)

Практическая работа с контейнеризацией: от управления готовыми Docker-образами и контейнерами до создания собственного образа и многоконтейнерного приложения.

- **Ключевые навыки:** Docker CLI, управление images и containers, сборка собственных образов через `Dockerfile`.
- **Networking:** port mapping, Docker Network и взаимодействие контейнеров по именам сервисов.
- **Web-инфраструктура:** Nginx, reverse proxy, FastCGI, HTTP.
- **Volumes:** монтирование конфигурации Nginx без пересборки образа.
- **Оркестрация:** Docker Compose для многоконтейнерного приложения.
- **Безопасность:** аудит Docker-образа с помощью `Dockle`.
- **Best practices:** минимизация слоёв образа, очистка package cache, корректные права доступа и отказ от использования `latest`.

## 🗄️ Работа с базами данных

### 🍕 [SQLB1: PostgreSQL и базовые SQL-запросы](./SQLB1_Basics.ID_574086-1)

Практическая работа с реляционной моделью данных и PostgreSQL.

- **Ключевые навыки:** `SELECT`, `WHERE`, сортировка, `DISTINCT`, `CASE`.
- **Фильтрация:** логические условия, диапазоны, математические операции.
- **Подзапросы:** scalar subqueries и подзапросы в `FROM`.
- **Форматирование:** конкатенация строк и вычисляемые поля.

### 🔗 [SQLB2: Sets, Subqueries and JOINs](./SQLB2_Retrieving_data.ID_574087-1)

Работа с операциями над множествами и различными типами соединений.

- **Операции над множествами:** `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`, `EXCEPT ALL`.
- **JOIN:** `INNER JOIN`, `LEFT JOIN`, `NATURAL JOIN`.
- **Продвинутые запросы:** подзапросы, `IN`, `EXISTS`.
- **Аналитика:** декартово произведение и работа с несколькими связанными таблицами.

### 🧩 [SQLB3: Advanced JOINs and CTEs](./SQLB3_Retrieving_data.ID_574089-1)

Углубленная работа с соединениями и аналитическими запросами.

- **JOIN:** `INNER`, `LEFT`, `RIGHT`, `FULL OUTER JOIN`.
- **Работа с отсутствующими данными:** `NULL`, `COALESCE`.
- **CTE:** использование `WITH` для структурирования сложных запросов.
- **Генерация данных:** `generate_series`.
- **Self-Join:** самосоединение таблицы для анализа связанных записей.

### 🛠️ [SQLB4: Data Manipulation](./SQLB4_DML.ID_574090-1)

Работа с изменением данных и поддержанием целостности реляционной базы данных.

- **DML:** `INSERT`, `UPDATE`, `DELETE`.
- **Массовые операции:** `INSERT ... SELECT`.
- **Динамические данные:** получение идентификаторов через подзапросы.
- **Self-Join** и операции над множествами.
- **Удаление данных:** целевые `DELETE`-операции.

### 👁️ [SQLB5: Views and Materialized Views](./SQLB5_Snapshots.ID_574092-1)

Работа с представлениями и материализованными представлениями PostgreSQL.

- **Views:** `CREATE VIEW`, `DROP VIEW`.
- **Materialized Views:** `CREATE MATERIALIZED VIEW`, `REFRESH MATERIALIZED VIEW`.
- **Генерация данных:** `generate_series`.
- **Операции над множествами:** `UNION`, `EXCEPT`.
- **Расчётные представления:** использование функций и вычисляемых значений.

### ⚡ [SQLB7: Indexes & Query Optimization](./SQLB7_Database_index.ID_574093-1)

Практика индексирования и анализа производительности SQL-запросов.

- **Индексы:** B-Tree, функциональные, многоколоночные, уникальные и частичные.
- **Query optimization:** анализ планов выполнения через `EXPLAIN ANALYZE`.
- **Scan types:** `Index Scan`, `Index Only Scan`.
- **Covering indexes:** подбор индексов под конкретные запросы.
- **Практика:** оптимизация запросов с `JOIN` и оконными функциями.

### 🧱 [SQLB8: Schema Design & Constraints](./SQLB8_Integrating_features.ID_574095-1)

Практика проектирования структуры базы данных и обеспечения целостности данных.

- **Schema design:** создание таблиц и определение структуры данных.
- **Constraints:** `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `CHECK`, `DEFAULT`.
- **Индексы:** составные уникальные индексы.
- **Sequences:** автоматическая генерация первичных ключей.
- **Window Functions:** `ROW_NUMBER()`.
- **Документирование:** `COMMENT ON`.
- **Массовая вставка:** `INSERT ... SELECT`.
