# 🐍 Python Bootcamp: OOP, Multiprocessing, and AsyncIO (Project 02)

## 📌 О проекте
Продвинутый проект, демонстрирующий применение различных парадигм программирования в Python (ООП, процедурный, функциональный и мультипарадигмальный подходы). Реализованы сложные сценарии с использованием многопроцессорности (`multiprocessing`) для симуляции массовых процессов с вероятностными моделями, а также асинхронного программирования (`asyncio`) для неблокирующих сетевых операций с надежной обработкой ошибок и динамическим интерфейсом.

## 📂 Структура проекта
Каждая задача оформлена как независимый модуль в собственной директории. Решения находятся в папке `src/`:
- 📁 **`src/exercise1/`** → 📄 `task1.py` (Симуляция экзамена: многопроцессорность, вероятностные модели, динамический консольный UI)
- 📁 **`src/exercise2/`** → 📄 `task2.py` (Асинхронный загрузчик изображений с валидацией путей и обработкой сбоев)

---

## 🛠 Стек технологий и инструменты
- **Язык:** Python 3.x
- **Стандартная библиотека:** `multiprocessing`, `asyncio`, `random`, `time`, `os`, `sys`, `urllib` (или `aiohttp` для асинхронных запросов)
- **Парадигмы:** Объектно-ориентированное (ООП), процедурное, функциональное программирование.
- **Концепции:** Межпроцессное взаимодействие (IPC, очереди), асинхронный ввод-вывод, вероятностное моделирование (золотое сечение), динамическое обновление консоли, graceful degradation (обработка ошибок без падения программы).

## ⚙️ Детальное описание выполненных задач

- **Part 1. Многопроцессорная симуляция и вероятностные модели (Task 01):**  
  Спроектировал и реализовал сложную симуляцию процесса сдачи экзамена. Каждый экзаменатор работает в отдельном процессе (`multiprocessing`), что обеспечивает истинный параллелизм. 
  - Реализовал логику распределения вероятностей ответов на основе пропорции золотого сечения, а также вероятностные модели «настроения» экзаменатора и длительности экзамена.
  - Организовал общую очередь студентов и механизм захвата свободного экзаменатора.
  - Разработал динамический консольный интерфейс, который обновляет таблицы статусов в реальном времени без мерцания (очистка экрана или управление курсором).
  - После завершения симуляции выполнил агрегацию данных: сортировку результатов, вычисление лучших/худших студентов и экзаменаторов, определение «лучших» вопросов и итоговый вывод об успехе экзамена (>85% сдавших).

- **Part 2. Асинхронность и отказоустойчивость (Task 02):**  
  Написал асинхронный обработчик для параллельного скачивания изображений.
  - Использовал `asyncio` для неблокирующего выполнения сетевых запросов, позволяя пользователю непрерывно вводить новые ссылки, пока предыдущие загружаются в фоне.
  - Реализовал строгую валидацию пользовательского ввода: проверка существования директории и прав на запись с циклическим запросом корректного пути.
  - Обеспечил отказоустойчивость: программа перехватывает исключения (битые ссылки, ошибки сети, таймауты), логирует их и не прерывает общий процесс выполнения.
  - По завершении всех задач вывел структурированную сводную таблицу со статусом каждой загрузки (Успех/Ошибка).

## 🚀 Как проверить

1. **Подготовка:** Убедись, что установлен интерпретатор Python 3.x.
2. **Запуск Задания 1 (Экзамен):**  
   - Перейди в директорию `src/exercise1/`.
   - Создай три текстовых файла с тестовыми данными: `examiners.txt`, `students.txt`, `questions.txt` (формат данных указан в условии задачи).
   - Запусти скрипт:
     ```bash
     python3 task1.py
     ```
   - *Ожидаемый результат:* Наблюдай за динамическим обновлением таблиц в консоли. После завершения всех процессов программа выведет финальный статистический отчет.
3. **Запуск Задания 2 (Скачивание изображений):**  
   - Перейди в директорию `src/exercise2/`.
   - Запусти скрипт:
     ```bash
     python3 task2.py
     ```
   - Введи путь к существующей директории для сохранения (например, `./downloads`).
   - Вводи ссылки на изображения по одной. Для завершения ввода ссылок нажми `Enter` на пустой строке.
   - *Ожидаемый результат:* Программа продолжит фоновую загрузку введенных ссылок, а по завершении выведет таблицу со статусом каждой попытки (включая обработку невалидных URL).
