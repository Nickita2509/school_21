# 🐳 DevOps Bootcamp: Containerization & Docker Compose (Simple Docker)

## 📌 О проекте
Фундаментальный проект по освоению технологий контейнеризации. Включает полный цикл работы с Docker: от управления готовыми образами и написания собственного мини-веб-сервера на C/FastCGI до создания оптимизированных Docker-образов, аудита их безопасности через Dockle и оркестрации многоконтейнерного приложения с помощью Docker Compose. Особое внимание уделено лучшим практикам (best practices), минимизации слоев и безопасной настройке окружения.

## 📂 Структура проекта
Решения и артефакты организованы в директории `src/` в соответствии с требованиями:
- 📄 **`src/report.md`** — Подробный отчет со скриншотами и выводами команд для Parts 1–3.
- 📁 **`src/server/`** — Исходный код мини-веб-сервера на C (FastCGI) и скрипт запуска.
- 📁 **`src/nginx/`** — Кастомные конфигурационные файлы `nginx.conf` (с проксированием и status-страницей).
- 📄 **`src/Dockerfile`** — Оптимизированный скрипт сборки кастомного образа (Part 4 & 5).
- 📄 **`src/docker-compose.yml`** — Файл оркестрации для многоконтейнерного развертывания (Part 6).

## ⚙️ Детальное описание выполненных задач

- **Part 1–2. Управление жизненным циклом контейнеров:**  
  Освоил базовые и продвинутые операции CLI: `pull`, `run`, `inspect`, `export`/`import`. Настроил маппинг портов (80/443), внедрил страницу статуса Nginx (`/status`) путем модификации конфигурации "на лету" через `docker cp` и `exec`. Продемонстрировал понимание разницы между образами и контейнерами, а также механизмов сохранения состояния.

- **Part 3. Разработка низкоуровневого веб-сервера:**  
  Написал собственный мини-сервер на языке **C** с использованием протокола **FastCGI**, возвращающий страницу "Hello, World!". Настроил его запуск через `spawn-fcgi` на порту 8080 и сконфигурировал локальный Nginx как reverse proxy, перенаправляющий запросы с порта 81 на бэкенд.

- **Part 4. Создание оптимизированного Docker-образа:**  
  Разработал кастомный `Dockerfile`, который:
  1. Компилирует исходный код C-сервера внутри образа.
  2. Запускает FastCGI-процесс и Nginx.
  3. **Оптимизация:** Объединил команды `RUN` для минимизации количества слоев (layers) и уменьшения итогового размера образа.
  4. Реализовал динамическое обновление конфигурации через **Volume Mapping** (монтирование локальной папки `./nginx`), что позволяет изменять `nginx.conf` без пересборки образа.

- **Part 5. Аудит безопасности (Dockle):**  
  Просканировал собранный образ с помощью инструмента **Dockle**. Выявил и устранил предупреждения, связанные с лучшими практиками безопасности (например, очистка кэша пакетного менеджера, избегание использования тега `latest`, настройка корректных прав доступа), добившись чистого отчета без ошибок (PASS).

- **Part 6. Оркестрация через Docker Compose:**  
  Спроектировал архитектуру из двух сервисов:
  1. **App Service:** Кастомный контейнер с C-сервером и внутренним Nginx (работает в изолированной сети Docker, без проброса портов на хост).
  2. **Proxy Service:** Официальный образ Nginx, выступающий в роли reverse proxy, который принимает запросы с порта 8080 хоста и перенаправляет их на порт 81 первого контейнера.
  Настроил корректное разрешение имен внутри Docker Network для взаимодействия контейнеров.

## 🚀 Как проверить

1. **Подготовка:** Убедись, что установлены `docker`, `docker-compose` (или `docker compose` V2), `gcc` и `spawn-fcgi` (для локального тестирования Part 3).
2. **Просмотр отчета:** Открой файл `src/report.md` для просмотра скриншотов выполнения Parts 1–3.
3. **Сборка и запуск проекта (Part 4–6):**
   Перейди в директорию `src/` и выполни:
   ```bash
   # Сборка образов, описанных в docker-compose.yml (включая кастомный Dockerfile)
   docker compose build
   
   # Запуск контейнеров в фоновом режиме
   docker compose up -d
